# Private retained Rust wire qualification protocol

This additive protocol observes the sixteen automatic-literal source recipes
from the frozen larger retained recipe module. Disabled-literal controls remain
parser controls. Source, schedule and parameters are independent inputs; actual
Rust wire block kinds determine the independent integer model's publication
history. Native C kind hypotheses are comparisons only, never parser inputs.

The test-only capture writes one raw source and complete frame per case plus a
bounded JSON array of block coordinates, kinds, incoming/candidate/committed
repeats, exact literal bytes, tail length and absolute-anchor sequence records
with wire offset values. Production token accessors still hide published data.
The frame reader independently checks exact source-size headers, final bits,
raw/RLE payloads, compressed extents and complete exhaustion. The frozen model
derives every token and repeat transition under those actual kinds. Complete
compressed payload decoding is a separate native CLI and Rust decoder check.

Capture directories must be fresh; Rust uses create-new file operations. The
source closure includes all compiled Rust inputs, fixture bytes, the capture
test, this protocol and independent Python model/recipe dependencies. Qualification
runs safe/all retained and framing regressions, strict all-target Clippy, fmt and
true no_std before comparing safe/all captures. The pinned v1.5.7 CLI identity
and exact decoding commands/bytes are recorded. Read-only adversarial controls
must reject forged kinds, tokens, repeats, frame extents and fixture sources in
ordinary and optimized Python without executing children. Failures and their
source snapshots remain separate from successful successor evidence.

This checkpoint is private shared entropy integration. It does not grant public
retained admission, claim C/Rust entropy equality, or replace the final feature,
platform, full-regression and measurement obligations.
