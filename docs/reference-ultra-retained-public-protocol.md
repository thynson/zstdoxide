# Retained Ultra public execution protocol

The source-only manifest `reference-retained-ultra-public/recipes.json` fixes
1593 requests and their expected tuples before execution: 1513 predecessors,
80 additions, 1423 successes and 170 resource rejections. Only predecessor index
1511 changes from resource rejection to success. Every other predecessor
response must remain byte-for-byte identical in both safe and all-feature Rust.

The controller freezes the complete qualified Rust snapshot, itself, both
independent offline auditor/control sources, all 3026 original predecessor
responses and their original receipt identity before running a new executable.
The original retained Optimal campaign is `retained-public-capture-v4`; its
completed positive commands and corrected exit-2 malformed controls retain
historical provenance. No old observation or helper is edited.

Normal and sanitized native adapters are reused from the pinned v1.5.7 Ultra2
campaign only after checking both executable hashes, all 26 compiled codec
translation units, complete dependency hashes and instrumentation metadata.
The same native adapter supports strategy 8. It is only a test oracle; the codec
implementation remains Rust. All copied executables are retained. Original
native dependency and copied executable hashes are checked again at completion.

The exact command plan is 3964: two release Rust builds, 3186 Rust encode calls,
620 native/bidirectional calls for the 61 new successes plus the predecessor
transition, and 156 malformed-packet calls. The latter comprise 39 independent
packets against all four adapters; each must exit 2 with no successful response.
Source requests and responses are bounded by the existing generic wire protocol.
A 3600-second campaign bound and per-command 300-second bound apply. Exact command,
input/output hash, exit status, environment and Cargo configuration are retained.

Every successful Rust tuple must equal independent resolution; safe/all complete
frame bytes must agree. Normal/sanitized native frames must agree. The 62
interoperable cases yield 248 native decodes of Rust frames and 248 Rust decodes
of native frames, each exactly equal to the independently generated source.
Rust and native entropy choices are not required to match. Retained strategy-8
frames must have the prescribed balanced block count and consume exactly.

The offline auditor reconstructs all request packets, classifications, tuples,
predecessor identities and decode obligations without executing children. It
rejects missing/duplicate commands, substituted exits, mismatched binaries,
changed plans, forged transition observations and coherent packet or decoded-byte
changes even when their local hashes are repaired. Both ordinary and optimized
Python must pass 21 negative controls and two positive audits with identical
reports. Every planned command must be consumed once by the audit.

Native capture and offline audit do not replace the full safe/isolated/all/release
regression, true no_std compilation, final public foreign interpretation and
concrete no-atomics code generation. Benchmarks require those completed gates and
an explicit task-owned CPU barrier before clocks.
