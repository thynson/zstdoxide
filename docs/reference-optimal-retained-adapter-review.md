# Retained ordinary Optimal observer review

The additive helper derives observation scaffolding from the immutable fresh helper.
It uses the same fourteen unique observation anchors, unchanged original provider
selection and original pointer-overflow attributes. The generated adapter diff is
retained with the exact original/generated opt source. No compression/search/path
statement or callback selection is replaced.

Transport is checked before metadata or allocation: source <=1,024, two to four
blocks of 64..512, exact schedule total and explicit bounded geometry. One ordinary
CCtx with bounded zero-initializing custom memory is used for each padding pass.
Begin receives the full pledge and complete parameters, Continue receives contiguous
slices of the original source, and End receives zero bytes at the consumed end.
The helper does not seed/reset any codec table between calls. Only observer counters,
copied sequence records and transient query snapshots reset per block.

Path observations retain 515 cells and check the remaining original 4,099-cell
allocation stays initialized zero. Complete search, frequency, sequence and literal
ranges must lie in live recorded allocations. Both compressed-state pointers must
be distinct live owned objects; stable owner indices describe swapping without
serializing addresses. Per-block publication observes both actual repeat arrays,
committed owner before/after, candidate owner, sequence count and trailing length.
The original first-block-only source increment and per-block short frontier/last
stretch initialization remain in upstream code.

Each Continue output is checked for one nonfinal block, bounded payload and exact
extent, after validating the first frame header and known content size. End must
emit the three-byte empty final raw block. The helper checks complete pinned decode,
source/frame/decode guards and custom owner guards before writing exclusive output
files and releasing all allocations. Source reads in observer code are bounded by
integer position checks; available match interpretation belongs to the independent
model. Original unused noDict pointer expressions and attributes remain unchanged;
sanitizer success is not an ISO C provenance proof.

The exact bounded plan inherits the pinned 89-file source closure and normal/ASan
workspace gates, compiles all 26 used units, and rejects 23 malformed packets per
build. Command deadlines remain 120 seconds, stderr 1 MiB, valid-run stdout 256 MiB,
other stdout 2 MiB, total logs 512 MiB, and campaign duration 1,800 seconds. Frame and
ledger artifacts are capped at 2,048 bytes. Full state, frame and allocator equality
is required across padding passes; sanitizer workspace size has the derived 3,584
byte difference. Source-only review and syntax checks are not execution evidence.


Strict syntax preflight initially rejected the deprecated buffer-less API
annotations for Continue/End. The oracle intentionally uses those pinned entry
points to expose exact block-call boundaries, as prior ordinary frame observers do.
The helper now defines upstream's `ZSTD_DISABLE_DEPRECATE_WARNINGS` before headers;
this removes only deprecation annotations. It does not change codec statements,
provider selection, bounds assertions, pointer attributes or sanitizer checks.
Both original failed diagnostics and corrected strict syntax logs are retained.
