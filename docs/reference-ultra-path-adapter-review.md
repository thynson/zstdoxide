# Coupled Ultra path adapter review

Read alongside `reference-ultra-path-protocol.md` and the ownership record in
`data-structures.md`. The additive adapter starts from the frozen wider Optimal
observer, with a retained source diff and digest for both adapters.

The original 15 unique-anchor hooks retain their parser statements, apart from
the explicitly substituted match-provider pointer. A sixteenth hook adds only
`PATH_ALTERNATIVE` after `withMoreLiterals` is computed. The hook reads the saved
match, native signed prices, existing next-cell price and predecessor index; it
writes only observer-owned copied fields and emits an event. It does not replace
comparison, repeat update, path write, frontier or frequency logic. Missing or
duplicate anchors must fail before compilation.

The policy word is validated before any upstream call and passed unchanged to
`ZSTD_compressBlock_opt_generic`. The descriptive strategy field uses btopt or
btultra consistently; ordinary search remains replaced by the scripted callback.
The source offset moves from 28 to 32 in every read, guard comparison, direct
match check, fingerprint and logical source copy. The corresponding packet cap
increases by four bytes. Descriptor-based O_NOFOLLOW/O_NONBLOCK/fstat handling
closes the prior path-open race and rejects special files before reading.

The additional 12-value alternative record uses signed 64-bit observer storage,
so negative LL increments remain signed without altering native arithmetic. Its
active flag is reset after emission and before each padding pass. Metadata,
every event and completion retain the policy discriminator. Existing complete
cell deltas, frequency/cache snapshots, sequence/literal checks and guards remain.

With at most 8192 source bytes, first scaled literal mass is at most 288 and
non-overlapping emitted literal updates contribute at most 16384. Sequence
counts are bounded by the source and minimum match length. Therefore this
scripted fresh envelope cannot approach the fractional raw-statistic upper bound
8388606; no unchecked assumption about arbitrary larger contexts is introduced.

Preflight must verify all frozen source hashes and the original upstream tree,
exact generated source and instrumentation manifest, normal/sanitized helper
syntax, dependencies and predefines, malformed packet construction and exact
220-command inventory. A positive capture requires complete independent replay
for every event and both padding/build equalities. No public strategy admission
or performance conclusion follows from this observer alone.
