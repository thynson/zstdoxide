# Retained Ultra2 complete-frame benchmark protocol

The 26 named inputs are frozen from the independently audited public native
campaign before any timing. They cover the four retained source boundaries,
raw/RLE/compressed histories, minimum-match settings, target requests and table
geometry endpoints. The projection compares exact safe/all frame bytes and
normal/sanitized native decoded sources, and retains the immutable source
manifest, native archive and original command receipt identities.

The benchmark owns each input and expected complete frame in ordinary `Vec`
values outside clocks. These are shared plain records; they do not require an
artificial unsafe representation. The codec's nineteen independent storage
features remain the only backend dimensions. A bounded borrowed reader validates
the pinned binary pack. The fixture is test input, never an untrusted public
codec API.

Every backend first runs without clocks. The complete frame, independent local
decode and allocator survey are checked outside timing. Each backend must emit
identical frame bytes and allocation ledgers. The tracking allocator records
attempts, grows, peaks, returned allocation, identity creation/drop and final
release; consistency and backend equality are required, without claiming these
counters are an independent allocator oracle. Offline controls mutate metadata,
commands, outputs, frames, source identities and coherent cross-backend records.

Timing may begin only after the full 22-product regression, 21 true no_std
configurations, final public foreign-platform checks, native interoperability,
all 21 clock-free backends and their adversarial controls are complete. The
coordinator records completed task-owned jobs and receipt/source identities.
This barrier does not establish operating-system idleness or exclude unrelated
desktop activity.

The controller builds every requested executable before measurement. Each case
has five samples lasting at least 100 ms. Only global one-shot compression and
output destruction are timed; source generation, allocation survey, validation
and decompression remain outside clocks. All 21 backends are measured, followed
by an independently built safe/all repeat. All 23 timed executables, samples,
frames, effective environments, compiler identity and exact sources are retained.

Throughput and compressed-size ratios describe these bounded workloads on this
host. The two aggregate safe/all comparisons must both be reported; conflicting
or small differences do not justify a general unsafe speedup claim. Complete
upstream parity remains outside this benchmark.
