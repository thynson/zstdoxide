# Generic adapter reuse for bounded public Ultra

The existing Rust reference_greedy_oracle, C reference_greedy_frames and binary
transport remain byte-identical. They forward complete public requests and frames
without implementing Ultra or predicting local admission. All 39 malformed
packets are retained for each of four builds. New tuples are independently
resolved from pinned source; C does not report its internally applied scalars.

The schema-7 controller retains 1269 predecessor recipes and adds 76 Ultra
requests. Its 1345-case source-only inventory predicts 1222 successes, 108
resource errors and 15 unsupported cases. Sixteen frame-equivalence groups retain
the original eight and add eight default/explicit Ultra groups. All 26 C codec
units are compiled in both normal and ASan/UBSan modes; the unchanged helper is
instrumented at link compilation, with no uninstrumented codec archive.

The exact expected 15132 commands comprise 66 metadata/build commands, 156
malformed exchanges, two Rust encodes per request and ten bidirectional exchanges
per admitted request. The predicted totals are 4888 decoded frames in each
direction and 800050968 decoded bytes. These are reviewed pre-execution values.
The independent auditor checks exact argv, environment, dependencies, sources,
requests, responses, scalar tuples, framing and decoded content without children.
It treats strategy 8 with the same independently bounded ordinary geometry as
strategy 7; strategy 9 remains unsupported.

A separate predecessor checker reconstructs all 4636 original successful encode
response identities from the pinned lossless archive. The native audit compares
these complete original responses against the new campaign, preserving complete
frames and scalar metadata under both implementations and both builds. Its v2
successor fixes only the original archive-index size bound and retains the prior
failed checker. This identity check does not require C/Rust entropy bytes to agree.

The complete production source inventory must remain unchanged during capture.
Public entry qualification is a separate prerequisite. This review does not
claim native execution, sanitizer success, completed public admission or timing.

The controller copies every named local input into the fresh capture directory
before any child starts. The auditor checks every captured source file against
its recorded hash, including files not individually listed in the reviewed
adapter pins. Matching forged before/after source hashes alone cannot pass.

A separately pinned production manifest binds every codec source, Cargo input,
allocator-support source and Rust adapter before native execution. Preflight and
capture check those exact hashes; the auditor compares captured source bytes and
the before/after metadata against that reviewed manifest. Coherently changing
source bytes and both metadata hashes cannot replace the pre-execution baseline.
