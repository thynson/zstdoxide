# Source-aware bounded Ultra admission design

This is a source-only successor policy; it does not enable public strategy 8.
Strategy 9 and its discarded initial pass remain a subsequent module.

The v7 projection retains every v6 file row, original column, source size and
request. It adds a v7 classification plus an independently reconstructed tuple
and additive-C-required marker. All 27 historical strategy-8 tuples are resolved
again from the pinned preset and known-source-size adjustment model. Existing
successes and all non-Ultra classifications remain unchanged. Original selector
inputs and numeric assertions are not rewritten to obtain new outcomes.

For a validated resolved Ultra tuple, the proposed local resource envelope is a
64..16384-byte complete fresh source fitting its window, window log at most 16,
hash/chain logs at most 12, search log at most 6 and target at most 4095. Source
size arithmetic and parameter validity precede this classification. Every other
valid Ultra request is resource-limited; Ultra2 stays unsupported. The envelope
is a local implementation bound, not a Zstandard format limit.

The projection imports immutable v6 classification/resolution code after verifying
its hash, prohibits child execution, reconstructs all original rows, checks exact
source and geometry boundaries, and rejects malformed types under both normal
and optimized Python. Public dispatch, complete-frame interoperability, platform
qualification and measurements remain separate tasks. A successful projection
alone is insufficient evidence to enable the public strategy.
