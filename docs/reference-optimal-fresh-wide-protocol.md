# Complete fresh Optimal observation protocol

`ZOPFW03\0` is additive to frozen retained transport. Its nine little-endian
u32 header words have the same meaning, followed by exactly one block length
and the complete immutable source. Source and block lengths are 64..16,384;
W10..16/H6..12/C6..12/S1..6, minimum 3..7, target 0..4095, literal mode 0 or 1.
The source fits its selected window. Maximum packet length is 16,432 bytes.
No dictionary, window expiry, LDM, worker or second block is admitted.

Every event uses the qualified complete 4,099-cell path and <=73,730-cell
search canonical-delta encoding. Baselines begin at zero per padding pass.
Full frequency tables, repeat owners, publication, sequence and query state
remain explicit. Maximum events are 65,536, line size 2 MiB and output 256 MiB.
Ordinary Begin/Continue with the entire source/empty End produces a complete
frame; the native match provider and all parser choices are unchanged.

The independent scalar/search model must reconcile both padding passes of all
twelve immutable small startup captures before wider native execution. Twenty
source-only recipes reuse those twelve sources, seven wider retained sources
as complete single blocks, and an incompressible 16 KiB source. They predict
raw/compressed publication, literal pricing, all minimum lengths, 65,536 short
heads, sufficient-length exits and actual reconstruction cell 4096. These are
hypotheses, not observations, until the subsequent native capture audit passes.
Public Optimal admission remains a separate gate.
