# Bounded public Ultra interoperability protocol

This additive campaign preserves all 1269 predecessor Optimal public source and
request pairs. An independent source-aware successor reclassifies strategy 8;
all preceding successful strategies stay admitted. New cases include every
unique ordinary Ultra source/request observation, small default levels 13/14,
explicit equivalences, minimum/target boundaries, complete-source and resolved
geometry rejection boundaries, and unsupported Ultra2. Public dispatch remains
a separate implementation/qualification gate.

The unchanged greedy-frame request/response transport and C adapter are reused.
They exercise the ordinary public C API with pinned zstd v1.5.7, not private
instrumented scalar setters. Request fields are level, window, chain, hash,
search, minimum, target, strategy and source-size hint. Parameter expectations
come from an independent pinned-source resolver; this does not claim to observe
C's internally applied scalar tuple. Maximum source/frame sizes are 4/5 MiB and
total regenerated source is capped at 256 MiB. Malformed binary requests retain
the original 39-case corpus for each of normal C, sanitized C, safe Rust and all
unsafe Rust builds.

Successful Rust safe/all encoders must return equal complete frames and resolved
parameters. Pinned normal and fully ASan/UBSan C must decode every Rust frame to
the source; Rust safe/all must decode every normal/sanitized C frame likewise.
Normal/sanitized C outputs must agree with each other. C and Rust entropy bytes
need not match. Exact command/source/environment/dependency inventories and all
raw request/response bytes must be preserved and independently audited. All 26
used C translation units are built with the selected instrumentation; no hidden
uninstrumented support archive is allowed. LeakSanitizer remains disabled on
this host and upstream sanitizer annotations remain unchanged.

A successful source recipe check is not native execution or public admission.
Existing captured frames and historical source/request inputs remain immutable.
