# Ordinary Ultra replay preparation

This additive model composes source-driven search with the coupled whole/fractional
path policy. It does not enable a Rust ordinary Ultra entry point or execute a new
native Ultra observer. The private Rust scripted constructor remains bounded to
8192 source bytes until the ordinary envelope is independently qualified.

The pinned reference is facebook/zstd v1.5.7, revision
`f8745da6ff1ad1e7bab384bd1f9d742439278e99`. `ZSTD_compressBlock_opt_generic` couples
frequency prices, extra saved-match alternatives and thorough path relaxation.
The tree search routines have no `optLevel` argument, but a different query schedule
changes their persistent state. Consequently a scripted-path match alone cannot
qualify the ordinary parser.

## Request ownership

`oracles/ultra_fresh.py` owns a copied policy 0 or 2 and an immutable original
`optimal_fresh_wide.Request`. `ZUFRS01\0` is followed by a little-endian u32 policy
and the exact complete original `ZOPFW03\0` packet, including its original magic.
This nesting preserves every original source/parameter/schedule byte. The maximum
packet size is twelve bytes larger than the original bound. Reject unknown or
boolean policies, non-exact request types, partial/trailing packets, and every
original geometry/source constraint before replay.

The original twenty complete fresh requests retain their 64..16384-byte sources,
window/hash/chain/search/minimum/target/literal settings, and single-block schedule.
Both policies use the same immutable request inputs. The old publication kind is
an explicit hypothesis for the new policy; its presence does not predict which
entropy representation Ultra will choose.

## Replay ownership and observations

Each replay owns complete search heads/children/short heads/frontiers, 4099 copied
path cells, all frequency counts/sums/cache values, append-only sequences and two
copied repeat owners. All links and predecessors are indices. Search runs from the
source at each actual query; captured native candidates never drive it. Canonical
sparse changes preserve the previous complete owner state between events.

Policy 0 delegates to the original path relaxation while using the reconciled
policy-bound frequency model. Policy 2 uses the independently native-qualified
Ultra path transitions and its twelve signed saved-match alternative operands.
Every event and block publication is tagged with the policy; non-alternative
events contain an explicit null alternative. Original stage/phase/publication
semantics remain unchanged.

## Qualification gates

`check_ultra_fresh_baseline.py` verifies the immutable original capture archive,
request identity and normal/instrumented equality. It then compares both padding
passes of every original native record with policy-0 successor replay after
removing only the additive policy/alternative fields and restoring the historical
protocol label. No original native input or stored observation is rewritten.

Preliminary policy-2 records on the same sources are source-only predictions.
Their event/alternative/sequence counts, branch coverage and transcript digests
are retained for review. Packet and complete-state forgeries are rejected without
child processes in normal and optimized Python. Additional source-only recipes
must close any missing Ultra-specific branches before a native command inventory,
read-only observer, malformed controls and adapter review are frozen. Native
ordinary capture, independent fixture projection/reading, Rust ordinary integration,
execution planning, shared-entropy publication and public admission remain open.
