# Ordinary lazy-family capture preflight

The controller and separate offline auditor were reviewed before first helper
execution. Their identities are retained in
`docs/evidence/2026-10-13-lazy-frame-preflight.json`. The new files preserve the
immutable Greedy controller/auditor and extend the depth-tagged command plan.

The exact plan is 510 complete scheduled frames and 39 additional aligned whole
comparisons per build, 45 incomplete headers and 51 malformed rejections. With
26 codec-unit compilations and all setup/dependency/link/metadata commands,
the complete campaign must contain exactly 1,276 commands. Each invocation has
a bounded timeout and separate capped logs. All 26 units and the helper are
instrumented in the sanitizer build; assembly, workers and leak detection remain
explicitly excluded. No prebuilt codec archive is substituted.

Each source/header and protected repository/input file is hashed before and
after every command. Output must be fresh and disjoint from reference/repository
paths. Normal and instrumented records and complete frame bytes must agree.
Every depth-zero predecessor observation is compared after changing only its
case-name prefix; scheduled and aligned whole-frame bytes compare exactly.
Actual candidate selection is never synthesized from Rust or a Python parser.

The offline auditor regenerates inputs and independently checks the exact ordered
snapshots, complete command arguments, compiler/dependency/binary identities,
environments, outcomes, logs, record replay, frames and complete artifact
inventory. It verifies predecessor equality independently of cross-build equality.
Per-file logs remain capped at 64 MiB and the aggregate retained log bytes are
capped at 256 MiB. The future packed observation collection will also have an
explicit 256 MiB aggregate cap; older fixture caps remain unchanged.

Normal and optimized Python each validate the plan and reject ten unsafe
controller inputs before any child or output creation (overlapping paths,
existing output, symlink traversal, internal reference, unavailable compiler and
changed pinned input). Each also rejects eleven malformed auditor transport or
incomplete-capture inputs and accepts a bounded artifact read. Child attempts
remain zero. These are preflight controls, not evidence that the future C
campaign succeeded; complete capture forgery controls follow actual observations.
