# Public Greedy capture controller before execution

The successor controller and independent auditor preserve the earlier capture
tools unchanged. The controller checks the reviewed adapter/protocol/recipe
identities and all pinned C source/header hashes before compiling in a fresh
external directory. It freezes 102 local source/input paths, including the
allocator dev dependency, and checks source identities after builds, before
every case and at completion. Output roots must be fresh, disjoint from the
project/reference trees and not a symlink. Paths and compiler discovery are
checked before any child process.

Each C mode compiles all 26 common/compression/decompression translation units
and the helper. Normal uses O2; sanitized uses O1, ASan+UBSan, no recovery and
frame pointers. Assembly, legacy codecs and workers are disabled. No archive is
linked. Dependencies and effective predefines are retained. Upstream sanitizer
annotations remain and LeakSanitizer is disabled. Safe/all Rust builds are
separate offline locked release builds with the pinned toolchain.

Every process receives an explicit environment, regular-file stdin, a 180-second
build/metadata or 30-second exchange timeout and bounded stdout/stderr streams.
Failure kills/reaps the process and preserves a failed report. The complete
campaign is capped at 1,800 seconds. All 39 negative packets run in four builds;
exit 2, a helper diagnostic, no successful response and no sanitizer diagnostic
are required. Only frozen admitted requests reach C encoding.

The expected successful campaign has 4,786 commands, 422 requests, 372 admitted
cases, 37 unsupported and 13 resource failures. Its 1,488 C decodes of Rust frames
and 1,488 Rust decodes of C frames must reproduce 413,994,400 source bytes in
total. Safe/all Rust and normal/sanitized C frames must be identical within each
language. C/Rust compressed bytes need not match. All 25 fixed Rust equivalences
remain required.

The offline auditor independently reconstructs exact compiler/link/build and
exchange commands, runtime environment, dependency closure, predefines, compiler
and executable identities, local source-key closure, every request and response,
historical resolved tuples, local admission and decoded-byte totals. It checks
bounded regular artifacts and exact protocol inventory without starting a
process. These checks will be exercised against the actual capture and forged
copies in the next work item; no completed-capture audit is claimed here.

Normal and optimized Python each regenerate the same plan and reject 11 bad
path/compiler/reviewed-input cases with child creation blocked and zero attempts.
All invalid preflights leave the fresh output absent. Python compilation and
shell syntax checks pass. Live aggregate oracle routing now selects this v3
campaign for both historical input sets; old v1/v2 controllers and evidence
retain their historical policy.
